## 🚀 FITUR UTAMA

- **Sistem Badak Otomatis**: Cukup ketik perintah, bot akan langsung mengirimkan QR Code dan Kode Pairing (Dual Login) langsung ke WA pembeli.
- **Anti-Kenon (Auto Read)**: Setiap pesan yang masuk ke bot akan otomatis dicentang biru (dibaca) seketika.
- **Anti-Banned / Anti-Blokir**: Menggunakan library Baileys 7.x terbaru dengan *delay* dan profil browser asli (Ubuntu/Chrome).
- **Spy Chat Buyer**: Fitur khusus Owner untuk melihat chat terakhir dari bot yang sedang disewa (via `!lihatchatbuyer`).
- **Auto Expired**: Bot otomatis mati dan menghapus sesi secara bersih jika masa sewa sudah habis.
- **High Performance**: Ringan, cepat, dan mendukung multi-device.
