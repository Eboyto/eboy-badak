# Eboygcr Badak WhatsApp

Bot WhatsApp Anti-Blokir, Anti-Banned, dan Anti-Kenon 100% Real Work.

## Fitur
- **Sistem Badak**: Sewa bot WA otomatis via Pairing Code / QR.
- **Anti-Kenon (Auto Read)**: Centang biru otomatis pada setiap pesan masuk.
- **Anti-Blokir & Anti-Banned**: Menggunakan Baileys 7.x dengan simulasi browser asli (Chrome/Ubuntu).
- **Sistem Log**: Owner bisa melihat chat terakhir dari buyer.
